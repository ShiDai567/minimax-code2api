# 安全说明与能力边界

- 上游凭证经 Fernet 加密存储，管理 API 不返回原值；API Key 仅存 SHA-256 摘要，明文只在创建时返回；管理响应禁止缓存。
- 管理 API 使用单一 ADMIN_TOKEN，无用户、角色、速率限制或完整审计。请勿直接暴露公网，必须通过 TLS 和网络访问控制保护。
- 模型发现、余额适配器的目标 URL 由部署者配置，并接收上游凭证；只能配置可信 HTTPS 地址。客户端不可选择 URL，禁止重定向。
- 未实现本地桌面端 auth-lease broker。仅使用有权使用的凭证；不要把密钥提交到仓库、日志或截图。
- 账号隔离、认证和任务防重有自动化测试，上游行为尚未真实验证。CLI 内部签名及路径随时可能变化。
- 网关只使用已验证且启用的同区域账号。验证需要用户提供一个已知可用模型；凭证替换后健康状态重置。
- 签到成功只是上游报告，奖励未确认到账；计划余额快照不是钱包余额或 API 消耗。请求 token 数不等于积分扣费。
- OpenAI 适配只支持非流式纯文本；工具、多模态和流式不支持。模型发现无默认 URL；没有硬编码模型或价格。
- 任务进程崩溃后，已提交的 pending 签到状态可能未知，不会自动重复领取。当前尚无自动对账/恢复接口，需操作员检查。
- 前端仍以 mock 运行，未完成管理 Token 安全交互和后端适配。生产级权限、密钥轮换、CORS 和部署编排仍待实现。
